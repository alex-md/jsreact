JSreact Image Hosting API

The QR code tool uses this API to host images.

Base URL: https://image-host.vs.workers.dev

Upload an image

Send POST /upload with a multipart form field named file.

curl https://image-host.vs.workers.dev/upload -F 'file=@image.png'

A successful response is HTTP 200 JSON containing the public image URL:

{"url":"https://image-host.vs.workers.dev/image/UUID.png"}

A missing file returns HTTP 400. Storage or processing failures return HTTP 500.

Retrieve an image

Send GET /image/{key} using the key returned by the upload. HTTP 200 returns image bytes with the uploaded content type and a one-year cache lifetime. Missing images return HTTP 404.

No API key is required. CORS permits cross-origin requests. There is no health endpoint.
